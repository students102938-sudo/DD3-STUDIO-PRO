# BOSS DD-3 Studio Digital Delay (Auto-Tempo + Studio Noise Cancellation)

## Features
- **Studio-Grade Adaptive Noise Cancellation (Zero Choppy/Kat-Kat Artifacts):**
  - Learns the background noise floor automatically during silent pauses.
  - Uses a **2.5:1 Soft-Knee Downward Expander** with **12ms smooth attack** and **220ms musical release** (never chops off vocal tails or guitar sustain).
  - Includes **Sub-Rumble High-Pass (85Hz)** and **Hiss/Hum Notch & Shelf Smoothing**.
- **Dual-Buffer Crossfade Delay Engine:** Zero pitch-warble or zipper noise when changing delay times.
- **Kick-Locked Auto-Tempo BPM Sync:** Detects tempo cleanly and locks in without drifting.

## Run Locally
```bash
pip install -r requirements.txt
python app.py
```
Open `http://localhost:5000` in your browser.
